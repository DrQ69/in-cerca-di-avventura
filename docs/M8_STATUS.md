# M8 — Definition of Done

Status: **Approved**

Primary specification: `docs/DEFINITION_OF_DONE.md`

M8 establishes the canonical completion model for ICA:

`SPECIFIED -> IMPLEMENTED -> VERIFIED -> APPROVED`

It defines separate completion criteria for components, assets, pages/templates, content/data, code/technical changes and PR/release work. It also defines defect severity, blocking rules, evidence requirements and a no-silent-waiver exception process.

M7.1 responsive verification is explicitly part of the Definition of Done for responsive P0/P1 components.

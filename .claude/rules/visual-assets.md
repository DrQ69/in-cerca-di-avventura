# Visual asset rule

- Consult `docs/ASSET_REGISTRY.md` before replacing, renaming or repurposing an existing visual asset.
- Consult `docs/ART_DIRECTION.md` when judging or introducing visual language.
- Preserve the official emblem and canonical asset geometry, proportions and identity.
- Do not treat a file as canonical merely because it exists in the repository.
- New visual work is `CONCEPT` or `CANDIDATE` until the owner explicitly approves it; never self-promote to `APPROVED`.
- Prefer reusable modular assets and web derivatives over destructive edits to source-quality masters.

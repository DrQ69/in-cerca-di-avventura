# Visual review

1. Read the relevant parts of `docs/ART_DIRECTION.md`, `docs/DESIGN_SYSTEM.md` and `docs/ASSET_REGISTRY.md`.
2. Compare the proposal with approved/canonical assets, not with generic fantasy references alone.
3. Check material language, lighting, palette hierarchy, heraldic geometry, readability, responsive viability and modular reuse.
4. Flag visual drift, unnecessary ornament, inaccessible baked-in text or unregistered asset assumptions.
5. Return `COHERENT`, `REVISE`, or `BLOCKED`, with the smallest specific corrections needed.

This skill does **not** grant authority to mark an asset `APPROVED`; canonical approval remains human.

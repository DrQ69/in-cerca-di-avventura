# Asset registration

Use only for an asset that actually exists or has a concrete reviewed candidate.

1. Read `docs/ASSET_REGISTRY.md` and relevant `docs/ART_DIRECTION.md` sections.
2. Assign/reuse the correct stable family code and numeric ID without renumbering existing identities.
3. Record status, purpose, actual path(s), canonical source vs web derivative, formats, constraints and intended reuse.
4. Do not invent missing files or metadata.
5. New assets remain `CONCEPT` or `CANDIDATE` unless the project owner explicitly authorizes `APPROVED`.
6. Modify only the registry unless the user explicitly requests related file operations.

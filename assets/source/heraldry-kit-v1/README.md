# Heraldry Kit v1.0 — Approved source assets

These PNG files are owner-approved AI-assisted reconstructions derived from the supplied composite heraldry sheet.

They are canonical project assets after explicit human approval, but they are **not** represented as the original native master files used to create the composite sheet.

Do not overwrite these source PNGs when creating web-delivery derivatives. Put optimized delivery assets in a separate web/delivery directory.

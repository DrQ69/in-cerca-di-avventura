# VR-0130 — Sorcery Event Results UI V1

**Primary QA Profile:** QAP-PAG  
**Secondary profiles:** QAP-CODE, QAP-DAT  
**Lifecycle claim:** IMPLEMENTED candidate; live E02 snapshot and browser verification pending.  
**Release readiness:** NOT_READY.

## Scope

Adds a detailed completed-event results page under `/beta/cronache/evento/`, a Sorcery snapshot overlay for completed events, and a Cronache link to detailed results.

## Data behaviour

- `data/events.json` remains the ICA event record.
- normalized Sorcery snapshots under `data/external/sorcery/events/<id>.json` can overlay verified result fields at runtime;
- attendance uses `participation_status: played`;
- `registered_no_show` records remain visible only in aggregate registration/no-show counts and are excluded from participant standings;
- detailed standings expose final position, Avatar, W-D-L, points, OMW and CMP;
- deck display derives ICA Atlas/Spellbook presentation from the raw Sorcery snapshot without mutating it: `Main + Site => Atlas`, `Main + non-Site => Spellbook`, `Avatar => Avatar`; `Collection` remains labelled with its source term.
